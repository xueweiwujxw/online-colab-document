# 管理控制台

`/admin` 只允许 `users.is_admin = true` 的登录用户访问。前端入口只是辅助；所有后台 API 都经过服务端管理员权限判断。

管理控制台提供：

- 查看和搜索全部用户；本地账号可修改显示名、邮箱和密码；OIDC 账号资料由身份提供方维护。
- 为账号授予或取消管理员角色，以及启用或禁用账号。管理员不能禁用自己或取消自己的管理员角色，避免把系统锁死。
- 查看 OIDC 的非敏感运行状态。`OIDC_CLIENT_SECRET` 只显示是否已配置，绝不返回实际内容。修改 OIDC 配置需更新部署环境变量并重启后端。
- 查看 RustFS 用量、按前缀筛选对象，并在二次确认后删除对象。
- 查看全部未删除文档，并执行审计化的软删除。该功能不改变文档的 owner/editor/viewer 协作权限模型。

所有删除操作均要求确认。后台操作会写入审计日志，审计元数据不包含密码、token、cookie 或 secret。

## 信息架构与运维约定

- 管理后台使用纵向侧边导航，将概览、用户、文件、对象存储、身份连接和审计日志拆分为独立工作区，避免把不同风险级别的操作堆叠在同一页。
- 审计日志使用一次性“应用筛选”模式，支持操作、对象、操作者、来源 IP 和时间范围；查询结果按时间倒序展示并可分页加载。筛选与审计查看只授予管理员。
- RustFS 采用对象浏览器模式：按前缀打开路径、显示对象元数据、在当前结果中搜索和排序、下载对象、复制对象路径；删除仍要求二次确认并记录审计事件。
- 设计参考：PatternFly Navigation、IBM Carbon Data Table/Filtering、MinIO Console Object Browser、NIST 审计日志管理指南。详见项目变更记录和外部来源链接。
