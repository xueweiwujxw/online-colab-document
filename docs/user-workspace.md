# 验证普通用户工作台

本页供开发和验收使用。日常操作请阅读[使用指南](usage.md)。

## 文档库

- 文档列表支持按名称或原始文件名搜索，并可按文件类型、当前用户权限和排序方式筛选。
- 筛选仅在浏览器中处理已获授权返回的文档；后端权限校验仍是下载、打开、编辑及管理接口的唯一授权依据。
- 每一行同时显示当前用户的能力（可管理、可编辑或只读），避免仅以隐藏按钮传达权限。
- 可通过文件选择器上传，也可把单个 `.docx`、`.xlsx` 或 `.md` 文件拖到工作台的上传按钮。上传限制仍由后端统一校验。

## 文档详情

- 文档详情显示文件大小、最近更新时间和当前用户权限，并把编辑、下载、权限、分享、版本操作放在同一操作区。
- 版本历史提供下载和（有编辑权时）恢复，完整历史可从“查看全部版本”进入。

## 验收路径

1. 使用普通本地账户登录 `/documents`。
2. 在搜索框输入完整或部分中文、英文文件名；确认列表即时收窄且“清除筛选”可恢复列表。
3. 分别选择文件类型、可编辑和可管理筛选项，确认只显示满足条件的已授权文档。
4. 键盘 Tab 进入搜索、下拉框、行操作和上传控件，确认焦点清晰可见。
5. 以 320、375、414、768px 宽度打开文档库与详情页，确认没有页面级横向滚动，操作按钮保持可点击。
