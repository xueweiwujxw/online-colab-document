# 使用在线协作文档服务

本指南面向日常使用者和管理员。它说明账户、文档、协作、分享与后台功能各自应在什么页面完成。

## 注册和登录

打开 `/register` 创建本地账户，或在登录页选择 OIDC 登录。OIDC 账户的密码由身份提供方维护，因此不能在个人资料页修改。

登录后，你会进入 `/documents`。在右上角打开个人资料可修改显示名、更新头像、修改本地账户密码，或撤销其他登录会话。

## 上传和管理文档

在文档库上传 `.docx`、`.xlsx` 或 `.md` 文件。你可以按名称、文件类型、当前权限和排序方式筛选列表。文档行会显示你当前的权限：可管理、可编辑或只读。

打开文档详情可以下载文件、查看大小和更新时间，并打开版本历史。owner 还可以删除文档、管理成员权限和创建分享链接。

## 协作和权限

文档权限如下：

- **Owner**: 管理成员、分享链接和删除，以及编辑、下载、恢复版本
- **Editor**: 编辑、下载和恢复版本
- **Viewer**: 下载和只读打开

在文档详情选择“权限”后，搜索账户、选择“只读”或“可编辑”，再授予权限。前端按钮不构成安全边界：服务端会在打开、下载、保存和建立 WebSocket 时重新验证权限。

## 分享文档

owner 可以创建只读或可编辑的分享链接，并可选设置过期时间。创建后的完整链接只显示一次，请在离开页面前保存到受控位置。之后可在分享管理页禁用链接。

未登录访问者可以使用有效链接访问文档。可编辑的分享链接只允许保存 Markdown；Office 文档仍遵循登录用户的编辑会话和权限链路。

## 使用版本历史

上传、Markdown 保存、Office 保存和恢复操作都会创建版本。进入“版本历史”可以下载旧版本。editor 或 owner 恢复版本时，系统会创建一个新版本，不会覆盖历史记录。

## 管理后台

管理员可打开 `/admin` 查看用户、文档、对象存储、OIDC 状态和审计日志。后台会记录管理动作，但不会在审计元数据中保存密码、令牌、cookie 或密钥。具体范围见[管理控制台](admin-console.md)。
